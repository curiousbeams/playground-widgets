---
title: Wolfram Cloud Notebooks
---

Embed public [Wolfram Cloud](https://www.wolframcloud.com) notebooks with the official
[wolfram-notebook-embedder](https://github.com/WolframResearch/wolfram-notebook-embedder),
wrapped as an anywidget. The notebook renders directly into the page (no iframe),
readers need no Wolfram account, and `Manipulate` controls stay interactive.

```md
:::{anywidget} widgets/wolfram-notebook.mjs

{
  "url": "https://www.wolframcloud.com/obj/jpoeschko/Public/Example.nb",
  "maxHeight": 640
}
:::
```

:::{anywidget} widgets/wolfram-notebook.mjs

{
  "url": "https://www.wolframcloud.com/obj/jpoeschko/Public/Example.nb",
  "maxHeight": 640
}
:::

The `{wolfram-notebook}` directive (from the local `plugins/wolfram.py` plugin) is the
equivalent convenience form — it also accepts a repo-local `.nb` path, which gets
`CloudPublish`ed on machines where deployment is enabled, optionally with
`:hide-input: true` to close the notebook's input cells (see [](./07.wolfram-language.md)):

```md
:::{wolfram-notebook} https://www.wolframcloud.com/obj/jpoeschko/Public/Example.nb
:max-height: 640
:::
```

:::{wolfram-notebook} https://www.wolframcloud.com/obj/jpoeschko/Public/Example.nb
:max-height: 640
:::

:::{note}
`{anywidget}` is the MyST built-in directive and renders both locally (`myst start`)
and on the deployed site. The `any:bundle` form used on the
[Observable page](./03.observable-notebooks.md) is a Curvenote-platform directive that
requires an `https` ESM URL and only renders on the deployed Curvenote site.
:::
