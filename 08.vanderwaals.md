In 3.020, you have probably covered thermodynamic state variables such as pressure, $P$, temperature, $T$, and the system's volume, $V$.

Equations of state are thermodynamic relations which relate these thermodynamic variables, and thus describe the state of a system under these physical conditions. They take the general form:

$$f(P, V, T) = 0$$

One simple such equation of state, pertaining to non-interacting particles, is called the ideal gas law and is given by:

$$f(P, V, T) = PV - nRT = 0$$

where $n$ is the number of moles of a substance, and $R$ is the ideal gas constant:

:::{wolfram}
:echo: true

UnitConvert["MolarGasConstant", "SI"] // N // QuantityMagnitude
:::

The equation's simplicity permits thermodynamic development without long and tedious equations.

The ideal gas law, however, has assumptions that are too simple to capture the behavior of real systems. Those assumptions are:

- Gas molecules are treated as point particles (occupying no volume)
- Gas molecules are allowed to interact with their container, but not one another

## Van der Waals Gas

Replacing these with less simple assumptions gives rise to rich phenomena, and in particular phase transitions. Johannes Van der Waals proposed a modified equation of state in his thesis which is now known as the Van der Waals equation.

$$\left(P + \frac{a}{\bar V^2}\right)\left(\bar V - b\right) = R\,T$$

where $\bar V$ is the molar volume, and $a$ and $b$ are constants relating to molecular interactions and volumes. Note that when both $a$ and $b$ are zero, the van der Waals equation reduces to the ideal gas law.

:::{wolfram}
:echo: true

vdWEquationOfState[a_, b_, r_][pressure_, molarVolume_, temperature_] :=
  (pressure + a/molarVolume^2) (molarVolume - b) == r temperature
:::

### Critical Behaviour

Later in 3.020, you will define various thermodynamic relations (Maxwell's relations), and bound their stability to materials properties. One of these relations, called the isothermal bulk modulus, relates the change in the pressure of a material following a change in its volume at fixed temperature:

$$K_T = -V\left(\frac{\partial P}{\partial V}\right)_T$$

In stable materials, pressure decreases with increased volume and thus the isothermal bulk modulus is positive. The reasoning goes as follows:

- If the bulk modulus becomes negative, then a decrease in volume would be resisted by decreasing pressure and the volume would continue to shrink until it goes to zero (or the bulk modulus becomes positive).
- Thus a negative isothermal bulk modulus would produce spontaneous volume changes — i.e. a phase transition.

Mathematically, we can express this stability condition as

$$\left(\frac{\partial P}{\partial V}\right)_T < 0$$

which highlights that in order for the system to be stable, pressure must decrease with increasing volume. For a gas obeying the van der Waals equation of state, there exists a critical temperature $T_c$ above which this is always satisfied — highlighting the stable region.

In order to find $T_c$ the conditions for a negative slope in pressure versus molar volume need to be worked out. As such, we rearrange for pressure:

:::{wolfram}
:echo: true

vdWEquationOfStatePressure[a_, b_, r_][molarVolume_, temperature_] =
 pressure /.
  First[Solve[
    vdWEquationOfState[a, b, r][pressure, molarVolume, temperature],
    pressure]]
:::

We require that the molar volume exhibits an inflection point. This amounts to the first and second derivatives (w.r.t. molar volume) vanishing:

:::{wolfram}
:echo: true

extremumEquation = Simplify[
  Derivative[1, 0][vdWEquationOfStatePressure[a, b, r]][vCritical, tCritical] == 0]
:::

:::{wolfram}
:echo: true

inflectionEquation = Simplify[
  Derivative[2, 0][vdWEquationOfStatePressure[a, b, r]][vCritical, tCritical] == 0]
:::

Solving our two equations for the constants $a$ and $b$:

:::{wolfram}
:echo: true

criticalSolutionsSubstitutions =
 Solve[{extremumEquation, inflectionEquation}, {a, b}][[1]]
:::

We can express the van der Waals equation of state at the critical point as:

:::{wolfram}
:echo: true

vdWEquationOfStateCritical[r_][pCritical_, vCritical_, tCritical_] =
 vdWEquationOfState[(9 r tCritical vCritical)/8, vCritical/3, r][
  pCritical, vCritical, tCritical]
:::

In this form, the equation can be solved for any of the critical variables in terms of the other two:

:::{wolfram}
:echo: true

criticalVolume =
 vCritical /.
  Solve[vdWEquationOfStateCritical[r][pCritical, vCritical, tCritical], vCritical][[1]]
:::

:::{wolfram}
:echo: true

criticalPressure =
 pCritical /.
  Solve[vdWEquationOfStateCritical[r][pCritical, vCritical, tCritical], pCritical][[1]]
:::

:::{wolfram}
:echo: true

criticalTemperature =
 tCritical /.
  Solve[vdWEquationOfStateCritical[r][pCritical, vCritical, tCritical], tCritical][[1]]
:::

Using these we can define the following dimensionless ratio:

$$\frac{3}{8} = \frac{P_C\,V_C}{R\,T_C}$$

### Non-dimensional form

Using these critical points, we can define new non-dimensional variables, so that we can plot the behavior as deviations away from criticality. We'll define the following three normalized variables:

$$\tilde P = \frac{P}{P_C}, \qquad \tilde V = \frac{\bar V}{V_C}, \qquad \tilde T = \frac{T}{T_C}$$

:::{wolfram}
:echo: true

pNormalvdWEquationOfStateNormalized[vNormalized_, tNormalized_] =
 pNormalized /.
  Solve[vdWEquationOfState[(9 r tCritical vCritical)/8, vCritical/3,
      r][pNormalized criticalPressure, vNormalized vCritical,
     tNormalized tCritical], pNormalized][[1]]
:::

### Instability

Regions of positive slope identify where the system is mechanically unstable.

Let's visualize this unstable region by plotting where the second derivative changes sign (the spinodal points). There is always one spinodal point separating local maxima from minima. We use our solution to eliminate the normalized temperature:

:::{wolfram}
:echo: true

normalizedTemperatureSubstitution =
 Solve[pNormalvdWEquationOfStateNormalized[vNormalized, tNormalized] ==
     pNormalized, tNormalized][[1]]
:::

:::{wolfram}
:echo: true

bulkModulus[vNormalized_, pNormalized_] =
 Simplify[-vNormalized Derivative[1, 0][
      pNormalvdWEquationOfStateNormalized][vNormalized,
     tNormalized] /. normalizedTemperatureSubstitution]
:::

We define the spinodal region as the volumes where this crosses the zero point:

:::{wolfram}
:echo: true

spinode[vNormalized_] =
 pNormalized /.
  Solve[bulkModulus[vNormalized, pNormalized] == 0, pNormalized][[1]]
:::

Overlaying the critical isotherm with the spinodal region gives [](#app:vdw-spinodal):

:::{wolfram}
:echo: true
:caption: The critical isotherm ($\tilde T = 1$) with the spinodal region shaded — the locus separating mechanically stable from unstable states.

(* #| label: app:vdw-spinodal *)

### Compressibility

The isothermal compressibility is related to the inverse of the isothermal bulk modulus:

$$\beta_T = -\frac{1}{V}\left(\frac{\partial V}{\partial P}\right)_T$$

This is an example of a susceptibility function, i.e. the measure of change of an extensive property upon variation of an intensive property. It's often convenient to work with susceptibilities when possible for two reasons:

- They can be experimentally measured
- They diverge at phase transitions

:::{wolfram}
:echo: true

compressibility[vNormalized_, tNormalized_] =
 Simplify[-1/vNormalized/
   Derivative[1, 0][pNormalvdWEquationOfStateNormalized][vNormalized, tNormalized]]
:::
